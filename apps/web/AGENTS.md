# 仓库约定

1. 开发页面和功能时按职责适度拆分：可复用界面放组件，独立状态或副作用放 Hook，与界面无关的纯逻辑放工具函数。简单且只在一处使用的逻辑可以保留原处。
2. 功能专用代码就近放在功能目录；仅将跨功能复用的代码提取到公共目录。页面目录中的非路由代码放在 `components`、`hooks`、`utils` 等路由生成器忽略的子目录。
3. 前端 `src` 中跨模块引用统一使用 `@/`（`@` 指向 `src`），包括类型、样式和动态导入。独立页面、布局组件、公共组件及公共 API/工具属于不同模块；同一模块内部的 `components`、`hooks`、`utils`、样式等可使用相对路径。生成器输出的跨模块引用也须遵守此规则；Node.js 脚本自身的引用不使用前端别名。
